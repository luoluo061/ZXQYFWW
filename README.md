# 财务找政策与政策性资金

这是 `finance-policy-funding` 分支，当前版本 `0.2.1-finance.1`，按财务每日工作指引整理的独立版本。每日台账一条政策一行，长期台账只保留判断和跟进所需信息。每天实际查看服务网和官方原文，按企业财务证据初筛，交由人员复核，再跟踪补料、办理、到账或税惠享受。

**安装请读 [财务版安装说明](INSTALL.md)，下载时选择本分支。** 通用政策和软件招标版在 [main](https://github.com/luoluo061/ZXQYFWW/tree/main)。

## 财务重点

| 方向 | 关注事项 | 核验重点 |
| --- | --- | --- |
| 税费优惠 | 研发费用加计扣除、六税两费等 | 纳税人身份、所属期、研发归集与辅助账、办理及享受证明 |
| 奖补兑现 | 财政奖补、研发和成果转化后补助、配套资助、资质衍生奖励 | 兑现条件、支持方式、申报与拨付节点、重复享受限制 |
| 人才用工稳岗 | 稳岗返还、扩岗、就业补贴 | 用工与参保缴费、人员条件、期间和材料 |
| 融资增信贴息 | 政策性贴息、增信或担保支持 | 政策对象、贷款或担保事实、贴息期间及兑现材料 |

首版不主动扩展商业银行产品或授信报价监测。高企、专精特新等认定由业务板块为主，财务跟衍生奖励、减免，或对转来的认定事项复核财务指标。资格、注册纳税归属及财务数值须有真实证据，模板中的空项不能当已确认。

## 每日交付

- 对话重点卡：P编号、用途、企业关联、最多3个门槛或待核条件、企业期限、原文、真实材料及待人员判断。北京时间09:00同步准备服务网与重点页，16:30按实质变化提醒。
- `每日检索政策台账.xlsx`：8列，按“日期＋P编号”一条政策一行，同日重复核查合并；直接看用途、待核条件、时间、材料及人工意见。
- `财务政策资金台账.xlsx`：10列，长期记录关键条件、资料、是否参与、办理进展和下一步。
- 两份Excel都带“资料明细”页。主表“资料与用途”点击后在表内定位到对应P号，再打开官方正文或下载真实附件；没有取得的表样明确列缺口，不提供假下载入口。单独转发Excel不依赖作者电脑的资料目录。
- 同名CSV、`财务政策资金明细.csv`、`每日检索运行日志.csv`用于备查与程序处理，保留完整字段、来源版本、财务证据、凭证、实际范围、观察计数、失败缺口和次日计划。
- 政策人工复核池及主动查阅记录：实际看过的暂不推荐、待核和历史项都保留。人员仍须主动浏览、自选细读并抽查未推荐。

内容采用通俗短标题、一句用途和最多3项关键待核，政策执行期与企业办理截止分开写。人员按编号在Codex回复，由系统回写，直接改Excel不会自动更新系统。没有新政策可以不发空日报，但运行日志必须留实际检索范围、缺口、人员反馈的在办进展及次日关键词建议，主表不造一条“无新政策”充数。完整日报时间仍待团队决定。两轮遇到同一公告按业务身份去重，独立批次与申报路径保留去向。原Word、Excel及历史示例不进入公开分支，也不当作今天新增。

## 判断与兑现

机器初筛、财务审核、人员参与分开。财务状态为待财务审核／可推进准备／待补齐／不适用／历史参考／已到账／已享受。可推进准备不自动变为参与；同一条真实人员回复可明确两个判断后一起记录。

待补齐须具体缺口、协同部门和时限；不适用须依据。已到账须实际到账日、会计凭证和归档证明；已享受须享受日、财税所属期、凭证和证明。免申即享不等于已到账，符合税惠条件不等于已享受。

## 程序

复用 `monitor.py`、`human_review.py` 的候选与人审，财务事项仍是 `kind=policy`，使用P/R编号。`finance_workflow.py` 负责每日日志、财务字段及人审兑现跟踪；运行其 `export` 会调用 `finance_workbooks.py` 自动生成两份Excel，不需要另复制本机生成脚本或安装Excel库。程序只用Python标准库，不联网、不自动测算税惠金额、不代替人员作涉税认定。

来源失效、404或登录障碍先记缺口，再查主管部门原文，不直接丢弃线索。全国且适用本企业的政策保留；注册、纳税、用工或项目地区分别核。私有画像和财务证明另行导入，各人的台账与定时任务独立。

```text
python -B -m unittest discover -s runtime/tests -v
python -B -m unittest discover -s tests -v
python tools/check_package.py
```

安装、真实网页试跑、定时登记及首次触发分别验收，见 [验证记录](VALIDATION.md)。本分支不修改本机现有定时任务。
