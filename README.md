# 中小企业服务网：政策与软件招标监测

把已验证的“发现机会 → 核官方原文和附件 → 企业画像初筛 → 人员主动查阅及抽查 → 人员决定 → 长期跟踪”流程安装到每个人自己的 Codex。

**给同事使用：先看 [安装说明](INSTALL.md)，把其中的安装指令发给自己的 Codex。** 选择负责政策、招标或两者；默认每天北京时间 **09:00、16:30** 检查。上午政策检查同步打开服务网和重点页面，提供筛选理由与待核条件；下午仅在有实质变化或需要处理时提醒。

## 安装后能做什么

- 在接收人的当前 Codex 对话中查新、解读、展示原文和实际取得的材料，并接收人员意见。
- 分别维护政策台账、招标台账；把实际看过的暂不推荐项也放进人工复核池。
- 人员可回复“恢复候选／维持暂不推荐／先补证据／仅作储备”审核机器筛选，再另行决定“参与／先补资料／不参与”。
- 记录人员真实查阅和判断；更新企业画像，但不把未知条件自动判为不满足。

`monitor.py`、`human_review.py` 只处理已采集数据，**不自行联网找政策**。网站读取由每次运行的 Codex 网页／浏览器工具完成。没有读到当次网页，就不能把旧数据重导出称为“检查完成”。

## 分发方式

1. **代码和通用规则**：本公开仓库，不包含真实企业画像、证书或历史台账。
2. **企业画像私有包**：由团队内部另行提供，导入个人工作目录。打包工具见 [安装说明](INSTALL.md#企业画像私有迁移)。
3. **个人运行记录和定时任务**：在接收人电脑与自己的当前对话中创建。安装器不会复制其他人的登录、任务 ID、聊天 ID、通知回执或人员审核记录。

每个人的台账独立，**当前版本不提供团队共享数据库**。跨人员汇总时用原文链接、公告／项目编号及标段核对，不能只用各自的 P/T/R 编号。不要用 Git 同步正在写入的 SQLite 数据库。

## 目录

| 路径 | 用途 |
| --- | --- |
| `install.py` | 将完整技能及运行资源安装到用户技能目录，支持保留修改的升级 |
| `skills/sme-opportunity-monitor/` | Codex 操作技能及安装、采集、人审指引 |
| `runtime/` | 工作目录初始化／检查、台账及人工复核程序、测试 |
| `templates/` | 通用规则、手动试跑及定时运行模板 |
| `tools/profile_bundle.py` | 企业画像与明确引用的证据文件私有迁移 |
| `plugin.json` | 另一种插件分发入口，使用时保留整个包 |

推荐先用 `install.py` 的本地技能安装方式，已做隔离目录测试。也提供符合当前官方格式的插件清单及仓库 marketplace；插件页面中的实际安装及展示仍需在接收人的应用版本验收。两种方式选一种，避免出现同名技能两份。

## 验证与限制

Python **3.10 或更新版本**，仅用标准库。Codex 可通过应用的 workspace dependencies 工具找到自带 Python，无需另买 API Key。

```text
python -B -m unittest discover -s runtime/tests -v
python -B -m unittest discover -s tests -v
python tools/check_package.py
```

自动化需要接收人的 Codex 桌面应用支持定时任务、能访问工作目录和网页；本地任务运行时电脑和应用需保持运行。网站账号、验证码、网络限制分别在该电脑处理，遇到阻碍保留实际失败范围并提醒；不会搬运登录凭据或更改 VPN。安装完成不等于网站登录、定时触发已验收，详见 [验收清单](INSTALL.md#验收与日常使用)。

实现依据：[官方技能文档](https://learn.chatgpt.com/docs/build-skills)、[官方定时任务文档](https://learn.chatgpt.com/docs/automations)、[官方插件打包文档](https://developers.openai.com/plugins/build/plugins)。

发行前实际验证及待验收边界见 [v0.1.1验证记录](VALIDATION.md)。
