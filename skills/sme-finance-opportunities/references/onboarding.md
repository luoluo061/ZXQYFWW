# 财务版安装与定时任务

定位完整包根：本 SKILL.md 所在目录或其祖先目录应有 `runtime/bootstrap.py` 和 `templates/finance-workspace/`。安装后的技能根可以直接含 runtime/templates/tools；源码中技能在 skills 子目录。仅复制技能目录不足以安装运行程序。先读根目录的 INSTALL.md 财务版说明；完整源码安装命令为 `PYTHON install.py install --edition finance`，不要误用普通版安装包或只拷 skills 子目录。

## 安装与实际试跑

1. 明确接收人的独立财务工作目录和人员标识，位置在源码/技能/插件缓存之外。财务分支只处理 policy，不把招标复制进日检交付，也不使用普通政策岗位的旧数据库、任务 ID 或已完成人审记录。
2. 查找 Python 3.10+，可用 Codex 的 workspace dependencies 工具定位自带 Python。本流程不需额外 OpenAI API Key。
3. 从完整包根执行 `PYTHON runtime/bootstrap.py init --workspace <独立绝对目录> --edition finance --scope policy --operator <人员标识>`，再检查 `profile.json`、来源和财务字段。`PYTHON` 替换为本机实际 Python；不要把初始化模板当事实。
4. 已有企业画像私有 ZIP 可通过 `PYTHON tools/profile_bundle.py unpack --bundle <私有ZIP> --workspace <工作目录>` 导入；只有明确要替换当前画像时加 `--replace-profile`，工具会保留备份。ZIP会替换画像，随后必须执行 `PYTHON runtime/bootstrap.py configure-finance --workspace <工作目录>`，保留企业事实与证据，并补财务配置/检索词和备份。再依次执行 `PYTHON tools/profile_bundle.py doctor --workspace <工作目录>` 校验迁入证据 SHA，和 `PYTHON runtime/bootstrap.py doctor --workspace <工作目录>` 做本地自检。直接在 init 用 `--profile-import <本机有效画像JSON>` 时会自动补财务配置；未提供的数值、身份、资质和财务字段继续待核。
   检查来源启用时区分“发现目标地区”和“适用归属”：已确认的经营/办公所在地、注册地或用户指定目标地区，均可支持启用相应省市来源做候选发现。已知在昆明即可查云南昆明，不必等注册、纳税或社保归属核完；这些归属字段保持待核，后续按具体条款判断适用。没有任何已知地区/用户目标时不默认云南，先保留全国适用发现并请人员补充目标地区。来源已启用不表示企业已满足地区条件。
5. 读初始化后的财务规则与手动试跑提示，使用接收人的正常网页/浏览器工具真实检索一次。至少核本轮真实查询范围和可用官方来源，保存候选、筛选池、每轮检索日志和两种财务交付。示例输入只验证程序，不算发现政策。
6. 人员完成必要的正常登录；不从其他电脑迁移密码、验证码、Cookies 或 VPN 配置。若登录/网络/工具受阻，交付已完成部分和缺口，不把本地程序通过称为网站试跑成功。
7. 展示岗位怎么自主浏览、审核推荐和抽查未推荐。收到安装并启用的明确请求后，真实试跑可用则继续注册两次任务；只要求改分支/安装文件时，不在开发者本机额外创建任务。

升级分别更新技能包和财务工作目录中的受管理代码/规则，保留真实画像、财务扩展、数据库、审核事件、材料、日志和已登记任务。自定义规则有冲突先比对 .new，不能静默覆盖。升级和重导出不算新查网站。

## 在接收人的当前对话登记

使用本机当前可用 `automation_update` 的实际 schema。优先 heartbeat，在这个固定财务对话中每天北京时间 09:00 和 16:30 各一条；时区 Asia/Shanghai。09:00 主动交接服务网页面与重点分析；16:30 按新机会、实质变化或需处理事项通知，无变化保持安静。每轮仍写本地日志，完整日报时间不固定。

创建前读工作目录 `data/automation_setup.json` 并核本机已有匹配任务。只把 ID 当定位线索，读回范围、财务版本、目录、时间和对话归属；有匹配则更新，不在每个新对话重建。没有工具就交付渲染后的提示词并标“定时尚未登记”，不直接写 automation.toml 代替工具。

把工作目录中的 Codex定时监测提示词.txt 和实际时段合成完整提示，不留模板占位符。保存工具成功返回的真实 ID、名称、范围、时区、时间、工作目录、当前对话及真实状态。失败/排队不能记 ACTIVE；提示词文件存在不表示任务已启动。读回工具结果核对；首次未到点触发时单列“尚未验收”。

两次任务串行访问同一个财务工作目录；不要同时拆成税务/资金多个并发写库任务。用户确需拆分时另做并发与主记录设计。保留原有通知设置，未另授权不改普通政策/招标岗位的任务。

## 交付与限制

最终说明独立目录、财务范围、画像缺项、真实检索结果、岗位日检表/长期台账、任务实际状态和未完成验收。每人的本地记录独立；跨人员汇总用官方链接、文号、办理期间等业务身份核对，不能只靠本机 P/R 编号。

本地定时需要接收人的 Codex 桌面应用支持任务、工作目录/网络可用，运行时电脑与应用保持运行；按该环境实际权限验收。不得将申报、纳税、贷款、资金兑现等外部办理写成自动完成。
